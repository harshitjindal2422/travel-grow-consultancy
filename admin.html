Security Architecture & Database Setup

Persistent Database & Zero Hardcoded Secrets

All customer enquiries, official quotations, holiday packages, and agency notes are persisted in data/enquiries.db via Node.js v22 built-in node:sqlite with zero external dependencies. Admin credentials use scrypt cryptographic hashing with 16-byte random salts. Plain text passwords are never stored.

Initial Admin Setup Command:
node scripts/create_admin.js <username> <email> <password> [fullName] [role]

Example:
node scripts/create_admin.js tg_admin admin@travelgrowconsultancy.com "YourSecurePass2026!" "Sarah Jenkins" admin

Environment Variables

  • WHATSAPP_PHONE: Set verified international WhatsApp number (e.g. +442079460991). Never set a dummy number.
  • PORT: Set custom listening port (default: 3000).
  • ADMIN_BOOTSTRAP_USER / ADMIN_BOOTSTRAP_PASS: (Optional) Automatically bootstrap initial admin account on container or cloud initialization.
